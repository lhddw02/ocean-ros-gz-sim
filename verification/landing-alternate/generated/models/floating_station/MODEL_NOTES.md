# Floating station geometry

Original model and UV mesh, licensed GPL-3.0-or-later with this ROS package.
The station uses the existing ASV Wave Sim Hydrodynamics system. It remains a
dynamic body with a real landing collision; the separate horizontal mooring
system restrains drift while leaving wave-driven heave, roll and pitch free.

- Hull and collision: 3 x 3 x 0.7 m, 1800 kg, uniform-box inertia.
- Nominal freshwater draft: 0.20 m, giving model-origin height about 0.15 m.
- Physical deck: local Z = 0.35 m; tag visual: Z = 0.352 m.
- Tag board: 0.60 m square; generated texture has a 0.40 m tag measured along
  the outside of its black border, plus 0.10 m white quiet margin per side.
- The explicitly mapped image has its right edge toward station +X and its
  top edge toward +Y. The printed target is mounted on the upward face.
- Pose telemetry: `/station/pose`, a single Gazebo Pose message at 30 Hz.

The board's visual texture is generated by the project setup tools. Change the
tag ID through those tools, keeping the physical size and detector size equal.
